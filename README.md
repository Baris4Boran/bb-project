# BB Project — Live Visual Performance System

**30 Kasım 2025 · Karga, Kadıköy, İstanbul**

BB Project is an experimental jazz group built around improvisation — no fixed structure, no predetermined endings. Every performance is different, and the visuals follow suit.

## The Idea

In most live performances, projection visuals run on a fixed timeline: a video plays, loops, or fades on a preset schedule regardless of what's happening on stage.

We didn't want that.

Since our music is fully improvised — a piece can end at any moment the band feels it's right — we built a system where the projection responds to the performance in real time. When the music stops, the visuals stop. When the energy shifts, the visuals shift. The screen is an extension of the stage, not a decoration running parallel to it.

## Stack

Built with [Next.js](https://nextjs.org/) — a real-time controllable visual interface designed to be operated live during performance.
